Destination Folder Structure

Files will be organized into these folders under the destination directory:

{{ dest_dir or '/path/to/dest' }}/
  movies-kids/      # Movies classified as "Kids"
  movies-adults/    # Movies classified as "Adults"
  tv-kids/          # TV shows classified as "Kids"
  tv-adults/        # TV shows classified as "Adults"

How to Configure

Set the environment variables before starting the application:

export MEDIA_SOURCE_DIR="/path/to/your/media"
export MEDIA_DEST_DIR="/path/to/organized/output"
python app.py

Or create a .env file in the project directory:

MEDIA_SOURCE_DIR=/path/to/your/media
MEDIA_DEST_DIR=/path/to/organized/output
